# Полный справочник кодов состояния HTTP (HTTP Status Codes)

Коды состояния HTTP — это стандартные коды ответов, которые сервер отправляет клиенту (браузеру или приложению) в ответ на его запрос. Все коды разделены на 5 классов по первой цифре.

---

## 1xx — Информационные (Informational)
Запрос принят, обработка продолжается.

| Код | Название | Описание |
| :--- | :--- | :--- |
| **100** | Continue | Сервер получил заголовки запроса, клиент может отправлять тело запроса. |
| **101** | Switching Protocols | Сервер согласен сменить протокол по запросу клиента (например, переход на WebSocket). |
| **102** | Processing | Запрос принят и обрабатывается, но ответ пока не готов (используется в WebDAV). |
| **103** | Early Hints | Позволяет серверу отправить предварительные заголовки (например, `Link` для предзагрузки ресурсов) до формирования основного ответа. |

---

## 2xx — Успех (Success)
Запрос успешно получен, понят и принят сервером.

| Код | Название | Описание |
| :--- | :--- | :--- |
| **200** | OK | Стандартный ответ для успешных HTTP-запросов. |
| **201** | Created | Запрос выполнен, в результате чего был создан новый ресурс. |
| **202** | Accepted | Запрос принят к обработке, но сама обработка еще не завершена. |
| **203** | Non-Authoritative Information | Сервер-посредник (прокси) вернул измененную версию ответа от исходного сервера. |
| **204** | No Content | Сервер успешно обработал запрос, но не возвращает никакого содержимого в теле ответа. |
| **205** | Reset Content | Сервер обработал запрос и просит клиент сбросить представление документа (например, очистить форму). |
| **206** | Partial Content | Сервер возвращает только часть ресурса (используется при докачке файлов или стриминге). |
| **207** | Multi-Status | Передает статус для нескольких независимых операций (WebDAV). |
| **208** | Already Reported | Элементы привязки уже были перечислены ранее в этом ответе (WebDAV). |
| **226** | IM Used | Сервер выполнил запрос `GET` для ресурса, и ответ представляет собой результат одной или нескольких манипуляций с экземпляром. |

---

## 3xx — Перенаправления (Redirection)
Клиент должен предпринять дополнительные действия для завершения запроса.

| Код | Название | Описание |
| :--- | :--- | :--- |
| **300** | Multiple Choices | У запрашиваемого ресурса есть несколько вариантов представления (например, разные форматы или языки). |
| **301** | Moved Permanently | Ресурс окончательно перемещен на новый URL. Все будущие запросы следует направлять по новому адресу. |
| **302** | Found | Ресурс временно находится по другому URL. |
| **303** | See Other | Ответ на запрос можно найти по другому URL с помощью метода `GET`. |
| **304** | Not Modified | Ресурс не изменялся с момента последнего запроса; клиент может использовать кэшированную версию. |
| **305** | Use Proxy | *(Устарел)* Доступ к запрашиваемому ресурсу должен осуществляться через указанный прокси. |
| **306** | Switch Proxy | *(Не используется)* Ранее означал, что последующие запросы должны использовать указанный прокси. |
| **307** | Temporary Redirect | Временное перенаправление с сохранением исходного HTTP-метода (например, `POST` остается `POST`). |
| **308** | Permanent Redirect | Постоянное перенаправление с сохранением исходного HTTP-метода. |

---

## 4xx — Ошибки клиента (Client Error)
Ошибка вызвана некорректными действиями или запросом со стороны клиента.

| Код | Название | Описание |
| :--- | :--- | :--- |
| **400** | Bad Request | Сервер не может понять запрос из-за неверного синтаксиса. |
| **401** | Unauthorized | Для получения запрашиваемого ответа требуется аутентификация (вход в систему). |
| **402** | Payment Required | Зарезервирован для будущего использования (иногда применяется в платежных шлюзах и API). |
| **403** | Forbidden | У клиента нет прав доступа к содержимому, хотя сервер понял запрос и знает, кто клиент. |
| **404** | Not Found | Сервер не может найти запрашиваемый ресурс по указанному URL. |
| **405** | Method Not Allowed | Метод запроса известен серверу, но отключен и не может быть использован для данного ресурса. |
| **406** | Not Acceptable | Сервер не может найти контент, соответствующий критериям, заданным в заголовках `Accept` клиента. |
| **407** | Proxy Authentication Required | Требуется аутентификация через прокси-сервер. |
| **408** | Request Timeout | Сервер решил закрыть неиспользуемое соединение, так как клиент слишком долго не отправлял данные. |
| **409** | Conflict | Запрос конфликтует с текущим состоянием сервера (например, конфликт версий при редактировании). |
| **410** | Gone | Запрашиваемый ресурс был окончательно удален с сервера без переадресации. |
| **411** | Length Required | Сервер отклонил запрос, так как не указан обязательный заголовок `Content-Length`. |
| **412** | Precondition Failed | Одно или несколько условий в заголовках запроса не выполнены сервером. |
| **413** | Payload Too Large | Размер запроса превышает лимиты, установленные сервером. |
| **414** | URI Too Long | URI запроса слишком длинный для обработки сервером. |
| **415** | Unsupported Media Type | Медиаформат запрашиваемых данных не поддерживается сервером. |
| **416** | Range Not Satisfiable | Диапазон, указанный в заголовке `Range`, не может быть выполнен (выходит за пределы размера файла). |
| **417** | Expectation Failed | Ожидание, указанное в заголовке `Expect`, не может быть выполнено сервером. |
| **418** | I'm a teapot | Шуточный код (RFC 2324): сервер отказывается варить кофе, так как он чайник. |
| **421** | Misdirected Request | Запрос был направлен на сервер, который не способен сформировать ответ. |
| **422** | Unprocessable Entity | Синтаксис запроса верен, но сервер не может обработать содержащиеся в нем инструкции (семантическая ошибка). |
| **423** | Locked | Запрашиваемый ресурс заблокирован (WebDAV). |
| **424** | Failed Dependency | Запрос не выполнен, так как зависел от другого запроса, который завершился ошибкой (WebDAV). |
| **425** | Too Early | Сервер не готов рисковать обработкой запроса, который может быть воспроизведен повторно (защита от replay-атак). |
| **426** | Upgrade Required | Сервер отказывается выполнять запрос по текущему протоколу, но может сделать это после обновления протокола клиентом. |
| **428** | Precondition Required | Исходный сервер требует, чтобы запрос был условным (для предотвращения конфликтов перезаписи). |
| **429** | Too Many Requests | Пользователь отправил слишком много запросов за определенный промежуток времени (Rate Limiting). |
| **431** | Request Header Fields Too Large | Сервер не желает обрабатывать запрос, так как его HTTP-заголовки слишком велики. |
| **451** | Unavailable For Legal Reasons | Доступ к ресурсу закрыт по юридическим причинам (например, по требованию государственных органов). |

## 5xx — Ошибки сервера (Server Error)
Сервер не смог выполнить корректный запрос из-за внутренней проблемы.

| Код | Название | Описание |
| :--- | :--- | :--- |
| **500** | Internal Server Error | Внутренняя ошибка сервера; сервер столкнулся с непредвиденной ситуацией. |
| **501** | Not Implemented | Метод запроса не поддерживается сервером и не может быть обработан. |
| **502** | Bad Gateway | Сервер, выступая в роли шлюза или прокси, получил недопустимый ответ от вышестоящего сервера. |
| **503** | Service Unavailable | Сервер временно не готов обрабатывать запрос (перегрузка или техническое обслуживание). |
| **504** | Gateway Timeout | Сервер, выступая в роли шлюза или прокси, не получил своевременный ответ от вышестоящего сервера. |
| **505** | HTTP Version Not Supported | Версия протокола HTTP, использованная в запросе, не поддерживается сервером. |
| **506** | Variant Also Negotiates | Внутренняя ошибка конфигурации сервера при согласовании содержимого. |
| **507** | Insufficient Storage | Серверу не хватает места для сохранения представления, необходимого для завершения запроса (WebDAV). |
| **508** | Loop Detected | Сервер обнаружил бесконечный цикл при обработке запроса (WebDAV). |
| **510** | Not Extended | Для выполнения запроса сервером требуются дальнейшие расширения. |
| **511** | Network Authentication Required | Клиенту необходимо пройти аутентификацию для получения доступа к сети (например, в публичных Wi-Fi сетях). |
